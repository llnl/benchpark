#############################
 Build and Run an Experiment
#############################

**Glossary terms:** :ref:`Benchmark <beginner-tutorial-glossary-benchmark>`,
:ref:`Experiment <beginner-tutorial-glossary-experiment>`, :ref:`System
<beginner-tutorial-glossary-system>`

Initialize the system and experiment using their Benchpark specs. Boolean variants use
``+`` to enable a value or ``~`` to disable it. Other variants use ``name=value``:

.. code-block:: console

    $ benchpark system init --dest=<system-id> <system> +/~<boolean-variant> <variant>=<value>
    $ benchpark experiment init <system-id> <benchmark> +/~<boolean-variant> <variant>=<value>

Create the experiment workspace:

.. code-block:: console

    $ benchpark setup <system-id>/<benchmark> <experiments-root>

The ``setup.sh`` script generated by ``benchpark setup`` activates Benchpark's Spack and
Ramble environments:

.. code-block:: console

    $ . <experiments-root>/setup.sh

Change to the workspace directory created by ``benchpark setup``. Set up the Ramble
workspace to build the benchmark and generate each experiment instance, then run the
experiments:

.. code-block:: console

    $ cd <experiments-root>/<system>/<benchmark>/<programming-model>/workspace
    $ ramble --workspace-dir . workspace setup
    $ ramble --workspace-dir . on

For workspace structure and additional build options, see :doc:`/build-experiment`. For
individual experiment instances, rerunning experiments, and combining workspaces into
one allocation, see :doc:`/run-experiment`.
