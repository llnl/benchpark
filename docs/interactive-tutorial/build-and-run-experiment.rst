#############################
 Build and Run an Experiment
#############################

**Glossary terms:** :ref:`Benchmark <beginner-tutorial-glossary-benchmark>`,
:ref:`Experiment <beginner-tutorial-glossary-experiment>`, :ref:`System
<beginner-tutorial-glossary-system>`

Initialize the Fluxtainer system from :doc:`add-a-system-config` and the HPL experiment
from :doc:`add-an-experiment`:

.. code-block:: console

    $ benchpark system init --dest=fluxtainer fluxtainer
    $ benchpark experiment init --dest=hpl fluxtainer hpl+strong caliper=time,mpi

Create the experiment workspace:

.. code-block:: console

    $ benchpark setup fluxtainer/hpl workspace

The ``setup.sh`` script generated by ``benchpark setup`` activates Benchpark's Spack and
Ramble environments:

.. code-block:: console

    $ . workspace/setup.sh

Set up the Ramble workspace to build HPL and generate each experiment instance, then run
the experiments:

.. code-block:: console

    $ ramble --workspace-dir workspace/fluxtainer/hpl/workspace workspace setup
    $ ramble --workspace-dir workspace/fluxtainer/hpl/workspace on

For workspace structure and additional build options, see :doc:`/build-experiment`. For
individual experiment instances, rerunning experiments, and combining workspaces into
one allocation, see :doc:`/run-experiment`.
