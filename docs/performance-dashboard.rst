======================
Performance Dashboard
======================

Benchpark's nightly CI produces performance timing data for every
system/benchmark/experiment combination it runs. This page shows that
data over time using `WARDEN <https://github.com/sandialabs/warden>`_, a
dashboard tool from Sandia National Laboratories for visualizing
hierarchical XML performance-report data as "dive-in"-able graphs.

`Dashboard <https://inspirational-olive-bird-0e73d942.plotly.app/>`_
